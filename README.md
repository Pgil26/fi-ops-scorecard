# FI Ops Scorecard (Floral Image)

Executive FI Ops board exported from Grok Build: Salesforce (units on hire, closed won, open trials, at-risk), RouteMap changeovers, and Geotab van activity, with a location filter. The numbers are baked into the page (`src/data/ops.ts`), so no login is needed.

**Public URL:** https://pgil26.github.io/fi-ops-scorecard/

## Structure
- `src/` — TanStack Start + React app (`src/routes/index.tsx` → `src/components/ops-board.tsx`, data in `src/data/ops.ts`).
- `docs/` — static build served by GitHub Pages (`main` branch, `/docs` folder). Generated by `scripts/publish-pages.sh`; do not edit by hand.
- `.vercel/`, `vercel.json` — original Grok Build / Vercel deploy output.

## Publishing to GitHub Pages
One command rebuilds `docs/`:

```bash
./scripts/publish-pages.sh
git add -A docs && git commit -m "Refresh FI Ops scorecard" && git push origin main
```

To refresh the numbers, update `src/data/ops.ts` first, then run the above.

What the script does: installs dependencies if needed, builds with `PAGES_BASE=/fi-ops-scorecard/` (which makes `vite.config.ts` use that base, prerender `/` to static HTML, and write to `dist/` instead of the committed `.vercel/output`), replaces `docs/` with the static output (keeping `docs/.nojekyll`), points favicon / `/__grok/*` links at `/fi-ops-scorecard/`, writes a static web manifest, and fails if `docs/index.html` references any local path outside the base or any missing file.

Normal `npm run build` (Vercel) is unchanged: base `/`, no prerender.
